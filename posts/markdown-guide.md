Nekote Blogで使えるMarkdown記法のサンプル集です。この記事のソース（`posts/markdown-guide.md`）と表示を見比べながら確認できます。

なお、見出しのレベルは自動で整えられます。記事タイトルが`h1`、本文でいちばん上の見出しが`h2`になるようにずれるため、`# `始まりで書いても`## `始まりで書いても同じ表示になります。

## テキストの装飾

**太字**、*斜体*、~~打ち消し線~~、`インラインコード`が使えます。

HTMLタグを併用すると、<mark>マーカー</mark>や<kbd>Ctrl</kbd>+<kbd>K</kbd>のようなキー表記、<small>小さい文字</small>も書けます（使えるタグは安全な範囲に限定されています）。

## リスト

- 箇条書き
- 箇条書き
  - 入れ子にできます

1. 番号付きリスト
2. 番号付きリスト

- [ ] タスクリスト（未完了）
- [x] タスクリスト（完了）

## 引用

> 引用文です。
> 複数行も書けます。

## リンク

- 外部リンク: [Nekote Blog](https://nekote.blog)
- 同じリポジトリ内の記事へのリンク: [ようこそ記事](./welcome.md)

記事ファイルへの相対パスで書いたリンクは、その記事の公開URLへ自動で書き換えられます。

## コードブロック

言語名を付けると、シンタックスハイライトが効きます。

```js
export function greet(name) {
  return `Hello, ${name}!`;
}
```

## 数式

インライン数式は`$`で囲みます: $a^2 + b^2 = c^2$

ブロック数式は`$$`で囲みます。

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

## コールアウト

`:::`で囲むと、補足や注意書きを枠付きで目立たせられます。

:::tip[ここがポイント]
`[...]`でタイトルを付けられます。**強調**や`コード`もそのまま使えます。
:::

:::warning
タイトルを省くと、アイコンと本文が横に並びます。
:::

種類は`tip`・`info`・`note`・`warning`・`alert`・`check`・`help`の7つです。`::::`で囲めば入れ子にもできます。

::::note[入れ子の例]
コールアウトの中に、

:::check
別のコールアウトを入れられます。
:::
::::

## 折りたたみ

HTMLの`<details>`で折りたたみを作れます。ブロックのHTMLタグは、前後に空行を空けて書きます。

<details>
<summary>クリックで開く</summary>

折りたたまれていた中身です。空行を挟めば、中身も**Markdownとして**解釈されます。

</details>
